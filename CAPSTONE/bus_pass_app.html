Object-Oriented Programming with C++ Course Mapping

            
Technical breakdown of how the PPT architecture is fulfilled by C++ OOP constructs.


            

                

                    1. Encapsulation:
                    class Passenger encapsulates passenger private records (ID, name, age) preventing unauthorized register modification.
                

                

                    2. Inheritance & Polymorphism:
                    Abstract Base Class BusPass defines pure virtual function virtual double calculateFare() = 0;.

                    - StudentPass : public BusPass overrides fare with 70% discount.

                    - SeniorCitizenPass : public BusPass overrides fare with 50% discount.

                    - CommuterPass : public BusPass calculates regular commuter fare.
                

                

                    3. File Handling & Atomicity (Slide 8):
                    PassManager uses std::ifstream to read passes.csv into memory, compares with Date::today(), writes updated records to passes.csv.tmp, and atomically renames the temporary file.
                

                

                    4. Algorithms:
                    Prefix ID hash sequencing (BP1001, P101), Julian day calendar arithmetic for leap-year-safe expiry validation, and status aggregation.
